# SHAKI MUSIC — نسخه دسکتاپ ویندوز

یک موزیک‌پلیر دسکتاپ با رابط تیره و مینیمال، کتابخانه محلی، جست‌وجوی آنلاین Internet Archive، صف پخش، علاقه‌مندی‌ها و دانلود فایل‌های قابل دریافت.

## ساخت EXE بدون نصب ویندوز روی سیستم خودت (از GitHub)

1. این ZIP را Extract کن و محتویاتش را داخل یک Repository جدید GitHub آپلود کن.
2. در GitHub وارد تب **Actions** شو.
3. اگر اولین بار است، گزینه **I understand my workflows, go ahead and enable them** را بزن.
4. از ستون سمت چپ **Build SHAKI MUSIC for Windows** را انتخاب کن.
5. روی **Run workflow** و سپس دکمه سبز Run workflow بزن.
6. پس از پایان موفق، وارد اجرای workflow شو و از بخش **Artifacts** فایل `SHAKI-MUSIC-Windows-Installer` را دانلود کن.
7. ZIP مربوط به Artifact را باز کن؛ فایل `SHAKI-MUSIC-Setup-1.0.0.exe` داخل آن است.

## اجرای توسعه‌ای روی ویندوز

Node.js 18 نصب کن، سپس در پوشه پروژه:

```bash
npm install
npm run dev
```

در ترمینال دوم:

```bash
npm run electron
```

برای ساخت EXE روی ویندوز:

```bash
npm run dist
```

## امکانات فعلی

- رابط دسکتاپ فارسی و راست‌چین، پنل کناری و پلیر ثابت
- افزودن پوشه موسیقی و اسکن زیرپوشه‌ها (تا عمق محدود)
- واردکردن دستی فایل‌های صوتی
- جست‌وجوی آنلاین Internet Archive و نمایش فایل‌های صوتی قابل دسترسی
- پخش فایل محلی و تلاش برای پخش مستقیم فایل آنلاین
- دانلود فایل آنلاین با انتخاب مسیر ذخیره
- علاقه‌مندی‌ها، صف پخش و ساخت پلی‌لیست
- پنل استودیو با کنترل‌های اکولایزر نمایشی

## نکات مهم و محدودیت‌های نسخه 1.0

- برای جست‌وجوی آنلاین، اتصال اینترنت و دسترسی شبکه به `archive.org` لازم است؛ دسترسی بدون فیلتر در ایران تضمین‌شدنی نیست.
- Internet Archive همه آهنگ‌های تجاری را ندارد. دانلود فقط برای فایل‌هایی فعال است که منبع در دسترس قرار داده است؛ مجوز و شرایط هر آیتم را بررسی کن.
- فایل‌های محلی از روی دیسک خوانده می‌شوند و به سرور دیگری آپلود نمی‌شوند.
- نسخه فعلی اطلاعات کتابخانه/پلی‌لیست را پس از بستن برنامه به‌صورت پایدار ذخیره نمی‌کند.
- اکولایزر در این نسخه رابط نمایشی دارد و هنوز روی صدای خروجی اعمال نمی‌شود.
- کاورهای نمونه و فونت آنلاین ممکن است برای بارگذاری به اینترنت نیاز داشته باشند.
- این نسخه یک پایه کاربردی و قابل توسعه است، نه ادعای پشتیبانی از تمام سرویس‌های موسیقی.

## توسعه بعدی پیشنهادی

ذخیره پایدار کتابخانه و پلی‌لیست، اسکن خودکار پوشه‌های انتخاب‌شده، موتور چندمنبعی قابل تنظیم، اکولایزر واقعی Web Audio، مدیریت دانلود و کلیدهای رسانه‌ای ویندوز.
